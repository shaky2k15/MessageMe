## 🛡️ Governance & Guardrails
Agents enforce the following rules to prevent architectural erosion:
1. **Lint Enforcement**: Custom rules block direct `TagsDbHelper` access from UI layers.
2. **Static Analysis**: Detekt prevents magic numbers and monolithic file growth.
3. **CI/CD Gates**: No code is merged unless Build, Lint, and Tests pass autonomously.
